Política de Privacidade

Como recolhemos, usamos e protegemos os teus dados pessoais.

Última atualização: Janeiro de 2026

1. Quem Somos

O ConectaLeiria é uma plataforma digital de procura de emprego dedicada ao Distrito de Leiria, que conecta candidatos a emprego com empresas e restaurantes da região.

Esta política explica como recolhemos e tratamos os teus dados pessoais quando utilizas o nosso site.

2. Dados que Recolhemos

Recolhemos os seguintes dados pessoais:

  • Nome completo e data de nascimento
  • Endereço de email e número de telefone
  • Localização (concelho do Distrito de Leiria)
  • Informações profissionais (currículo, experiência, escolaridade)
  • Dados da empresa (nome, morada, tipo de negócio)

3. Como Usamos os Teus Dados

Os teus dados são utilizados exclusivamente para:

  • Criar e gerir a tua conta na plataforma
  • Permitir que empresas encontrem o teu perfil
  • Melhorar os nossos serviços e funcionalidades
  • Enviar notificações relevantes sobre oportunidades de emprego

4. Partilha de Dados

Não vendemos nem partilhamos os teus dados pessoais com terceiros para fins comerciais. Os teus dados são apenas visíveis para:

  • Empresas registadas na plataforma (apenas dados do currículo)
  • A equipa do ConectaLeiria para suporte técnico

5. Os Teus Direitos

Tens o direito de:

  • Aceder aos teus dados pessoais
  • Corrigir dados incorretos
  • Solicitar a eliminação da tua conta e dados
  • Retirar o consentimento a qualquer momento

Para exercer estes direitos, contacta-nos através da página de Contacto.

6. Segurança

Utilizamos medidas de segurança adequadas para proteger os teus dados, incluindo encriptação e armazenamento seguro através do Supabase.

7. Contacto

Para questões sobre privacidade, contacta-nos em:

Email: privacidade@conectaleiria.pt

Plataforma: Página de Contacto
